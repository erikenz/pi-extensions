# pi-extensions

A collection of extensions and packages for the [Pi coding agent](https://github.com/earendil-works/pi-coding-agent).

## Packages

| Package | Version | Description |
| :-- | :-- | :-- |
| [`@erikenz/pi-model-switch`](./packages/pi-model-switch) | [![npm](https://img.shields.io/npm/v/@erikenz/pi-model-switch.svg)](https://www.npmjs.com/package/@erikenz/pi-model-switch) | Fast model picker and favorite model cycling shortcuts for Pi. |

## Development

This repository is organized as a [pnpm](https://pnpm.io) workspace.

### Commands

- **Install dependencies**: `pnpm install`
- **Run tests**: `pnpm test`
- **Typecheck**: `pnpm typecheck`
- **Lint & format check**: `pnpm run check`
- **Fix formatting**: `pnpm run fix`
